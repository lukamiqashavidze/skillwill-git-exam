# SkillWill — Git პრაქტიკული გამოცდა

ეს არის საგამოცდო პროექტი Git-ის ძირითადი სამუშაო პროცესის დემონსტრირებისთვის.

## ეტაპი I
- `git init -b main`
- საწყისი `index.html` და `README.md`
- `git add .` და `git commit`

## ეტაპი II
- `feature-header` branch
- ახალი header ბმული
- merge მთავარ განშტოებაში

## ეტაპი III
- `nav-feature` და `nav-alt` branch-ებში ერთსა და იმავე ნავიგაციის ხაზზე სხვადასხვა ცვლილება
- merge conflict-ის წარმოქმნა და გამოსწორება

სრული ლოგი და კონფლიქტის დეტალები იხილეთ `EXAM_REPORT.md`-ში.

## გახსნა
გახსენით `index.html` ბრაუზერში. Git ისტორიის სანახავად გამოიყენეთ `git log --oneline --graph --all`.

## GitHub
GitHub-ზე გამოქვეყნება საჭიროა შემფასებლისთვის. ჯერ არ არის შესრულებული — საჭიროა ანგარიშის ავტორიზაცია და რეალური remote URL.
